What it costs to build and run DragonCandy.

$710–765 / month
Stage: Pre-revenue Users: ~30 Team: 3 founders Paying customers: 0 (by choice)

In plain terms: like a lemonade stand, we pay monthly rent for tools, a little per-customer for things like AI answers and emails, and a few once-a-year fees. Right now the single biggest cost isn't running the app for users — it's the Claude subscription we use to build it.

01Four kinds of cost
🔁
Monthly
Subscriptions we pay every month, rain or shine — building tools, hosting, database.
📈
Usage-based
Like water from a tap — more customers means more AI answers, emails & texts.
📅
Yearly
A once-a-year fee — the domain name and the Apple Developer membership.
🧱
One-time
Pay once, ever — like a Mac to build the iPhone app on.

The one thing to understand

There are two Claude bills — and they're not the same thing.

🛠️ Building the app FLAT
A team subscription the founders use to develop DragonCandy. Costs the same no matter how many customers we have.
~$500 / month · Claude Team Premium (5 seats)
🤖 Running it for users GROWS
Pays per-answer when Donny (our AI) helps real users. Tiny today, grows with users — and capped at 15% of revenue by design.
~$10–25 / month today · pay-as-you-go API

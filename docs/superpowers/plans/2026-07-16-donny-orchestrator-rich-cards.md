# Donny web-chat rich creator cards (Option B) — Implementation Plan

> REQUIRED SUB-SKILL: subagent-driven-development or executing-plans.

**Goal:** Render the `find_creators` results in the CONSUMER web Donny chat (`donny-orchestrator`) as **avatar rich cards** (one `DonnyRichCard` per creator) instead of only a text list, reusing the existing `creator_profile` card.

**Architecture:** Cards flow as a **deterministic side-channel that bypasses the LLM** — the `find_creators` sub-agent returns structured `cards[]`, the orchestrator threads them straight into the SSE `done` event, `useDonny` persists them to a new nullable `donny_messages.rich_cards jsonb` column, and `DonnyMessage` maps them to `DonnyRichCard`. The text answer + `suggested_actions` stay LLM-mediated.

**Tech Stack:** Deno edge fn (donny-orchestrator), React/TS frontend, Supabase (nullable column migration).

## Global Constraints
- **Additive + backward-compatible ONLY.** Never rename/drop the existing singular `donny_messages.rich_card`. The new column/fields are optional/nullable so INTERNAL Donny (`donny-chat`, `useInternalDonny`) — which shares `donny_messages`, `DonnyMessage.tsx`, `types/donny.ts` — renders byte-identically (it never sets `rich_cards`).
- **Deploy ordering:** apply the migration to prod BEFORE the frontend merges (Vercel deploys frontend on merge; the `useDonny` insert writes `rich_cards` and would 400 on a missing column). The edge-fn deploy is forward-compatible (old client ignores the extra `rich_cards` SSE field) and can deploy any time.
- Cards **COMPLEMENT** the "View" buttons: each card already has "View Portfolio" + "Invite", so trim the sub-agent's per-creator `suggested_actions` to a single "Browse all creators".
- `donny-orchestrator` is `verify_jwt=true` → deploy WITHOUT `--no-verify-jwt` (confirm via `list_edge_functions`).

export interface CreatorCard {
  type: "creator_profile";
  data: {
    id: string; name: string; avatar_url: string | null; profile_slug: string | null;
    platforms: string[]; niche: string; rating: number; project_count: number;

No other sub-agent path changes.

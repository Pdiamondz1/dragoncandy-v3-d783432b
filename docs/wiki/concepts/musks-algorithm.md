# Musk's Algorithm

Governing philosophy applied to every recommendation, prompt, and PR
in DragonCandy development.

## The Five Steps

1. **Question** every requirement (including the user's — push back
   when wrong)
2. **Delete** every step, field, click, and keystroke that can go
3. **Simplify** what survives
4. **Accelerate** cycle time
5. **Automate** last — never automate a broken process

## Application in DragonCandy

- North star: "Less typing = more margin" — every flow under
  10 keystrokes by Month 6
- Surface priority: voice → camera → paste-URL → tap-a-chip → typing
- Target: paid campaign in under 60 seconds
- Every recommendation ends with: what it deletes, simplifies,
  automates, and the keystroke count removed

## Corollaries

- Bulk changes break builds — surgical, one-change-at-a-time
- Setup disguised as action (show value before collecting info)
- Never block launch on third-party API approvals

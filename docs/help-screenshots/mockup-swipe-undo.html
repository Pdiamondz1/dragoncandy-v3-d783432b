Design Notes

  • Undo toast: 5-second window with progress bar. Clicking "Undo" removes campaign from skippedIds and restores it to the top of the stack. Toast auto-dismisses.
  • Database persistence: New campaign_skips table (user_id, campaign_id, skipped_at, restored). Skips are written on swipe, removed on undo/restore.
  • Cycling: When fresh campaigns run out, "Show Skipped" button loads previously-skipped campaigns back into the swipe stack. Skips are soft — campaigns reappear rather than being permanently dismissed.
  • Desktop grid: "Previously Skipped" collapsible section below main grid. "Restore" button moves campaign back to the main feed.
  • Analytics: Skip data feeds into Donny AI matching — frequently-skipped campaign types deprioritized in future recommendations.
  • Session undo vs DB restore: Undo toast is immediate (in-memory). "Restore" and "Show Skipped" read from DB. Both paths result in the campaign reappearing.

Design Notes

  • Badge color: Pink-dark (#EC4899) — matches DragonCandy secondary CTA color, stands out against both teal and gray
  • Badge caps at 9+ to keep it compact
  • Hook: New useTotalUnreadCount hook wraps existing useConversations — sums all per-conversation unread_count values
  • Refetch: Every 30 seconds + on window focus + on new message realtime event
  • Email: Role filter removed from send-notification-email — creators now receive message emails too
  • Clears: Badge decrements as user opens each conversation (existing mark-as-read logic)

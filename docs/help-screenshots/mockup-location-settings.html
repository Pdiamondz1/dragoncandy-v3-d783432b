Design Notes

  • Schema: Add stripe_account_id and stripe_onboarding_complete columns to org_units table (nullable)
  • Edge function: Update create-restaurant-connect-account to accept org_unit_id param and write Stripe account to org_units instead of business_profiles
  • Social media: Fix AccountsTab to correctly pass activeOrgUnit.id to Outstand proxy. The org_unit_id column already exists on business_outstand_accounts
  • Feature gate: New useLocationReadiness(orgUnitId) hook checks if both social + Stripe are connected. Returns { isReady, missingSocial, missingStripe }
  • Backward compat: Existing user-level Stripe account in business_profiles is preserved as fallback for businesses without org_units
  • Same Stripe account OK: Multiple locations can reference the same stripe_account_id — each location just links to it

Section 3

Executive Summary

The Problem

Today, social media posting happens entirely outside DragonCandy. Restaurants approve creator content in-platform, then manually re-upload it to Instagram, TikTok, and Google Business Profile. Creators cross-post deliverables by hand. Brands have zero visibility into when or where sponsored content actually goes live. The loop between content creation, approval, and publication is broken.

The Solution

Outstand.so closes the loop. With a single integration, content created and approved inside DragonCandy can be published directly to social media — all without leaving the platform. Donny AI orchestrates the entire process: writing captions, picking optimal posting times, and tracking performance across every channel.

Integration Partner: Outstand.so

Unified social media API covering 10 platforms, including Instagram, TikTok, YouTube, Google Business Profile, LinkedIn, Facebook, X, Threads, Bluesky, and Pinterest.

$0.01/post 25-tool MCP server White-label ready OAuth management

Key Technical Decisions

DecisionDetail
API ProxyAll Outstand API calls through Supabase Edge Functions — never direct from client
Token StorageOAuth tokens encrypted with AES-256 in Supabase, following toast_connections pattern

Social Account LinkingNew social_connections table linking profile_id to Outstand social_account_id
Post RecordsNew social_posts table tracking all posts (post_id, platform, status, analytics)

Section 11

Guiding Principles

Donny First, UI Second

Every social action achievable via Donny. Manual UI is fallback. This aligns with the “less typing” philosophy at the core of DragonCandy.

Never Store Secrets Client-Side

Outstand API keys and OAuth tokens stored in Supabase with AES-256 encryption. Edge Functions proxy all calls.

White-Label Everything

Users see “DragonCandy Social” — not “Powered by Outstand.” The integration is invisible to end users.

Build for Reuse

Phase 1 components are role-agnostic. Phases 2–3 configure, not rebuild. Shared foundation, role-specific UX.

Respect Existing Patterns

Follow toast_connections pattern for OAuth. Follow existing Edge Function patterns. Match current codebase conventions.

RLS on Everything

All new social tables follow existing Row Level Security patterns. Users only see their own data. No exceptions.

Restaurants

  • Instagram and Google Business Profile are non-negotiable for local discovery
  • 61% of diners say TikTok food content directly influences where they eat
  • Short-form video (Reels, TikTok, YouTube Shorts) is highest-engagement format
  • Staff-led content (EGC) is emerging as a powerful, underused asset in hospitality

Creators

  • Creator economy revenue growing 16.2% YoY to $20.6 billion in 2026
  • Shift toward long-term brand partnerships over one-off sponsorships
  • Micro-influencers with local community trust preferred over large national creators
  • 92% of consumers trust UGC over traditional brand advertising

Brands

  • Focus on 2–3 platforms done well rather than spreading thin
  • AI-driven personalization is becoming foundational
  • Performance-driven influencer marketing — brands want measurable ROI
  • Authenticity and values-driven branding matter more than polish

Login Polish + Role Selection: Approach Options

How should we structure the signup flow and login polish?

A

Minimal Polish — Keep Current Structure

Polish the existing AuthPage and AuthForm in-place. Replace inline radio buttons with two styled role cards within the same form view. Add card container, improve input styling, style social buttons. Fewest files changed.

Pros

  • Smallest diff — low risk of breaking auth flow
  • Role cards and form on same screen = fewer navigation steps
  • reCAPTCHA, validation, error handling stay untouched

Cons

  • Signup form gets long on mobile (role cards + name + email + password)
  • Doesn't match the spec's "role selection FIRST" requirement
  • Less visual impact — incremental improvement
B

Multi-Step Signup — Role Screen First (Recommended)

Add a role selection step as a separate screen/view before the signup form. User clicks "Sign Up" → sees two large cards ("I'm a Business" / "I'm a Creator") → taps one → slides to the signup form with role pre-filled. Login page gets full visual polish with card container, styled inputs, "or continue with" divider, branded social buttons.

Pros

  • Matches the spec exactly — role selection is a dedicated first step
  • Clean UX: one decision per screen, no scroll on mobile
  • Role cards get full visual treatment (icons, colors, descriptions)
  • Signup form is shorter (no role picker inline)

Cons

  • Adds a new component (RoleSelection) and step state management
  • One extra tap before the signup form
C

Full Redesign — Separate Auth Pages

Split login and signup into completely separate page components. Signup becomes a multi-page wizard: Role → Details → Verification. Login gets its own dedicated page with maximum polish. New route structure.

Pros

  • Maximum flexibility for each flow
  • Cleanest code separation
  • Easy to A/B test different flows later

Cons

  • Largest scope — high risk of breaking existing auth logic
  • Duplicates shared logic (OAuth, reCAPTCHA, redirect handling)
  • Overkill for what's being asked — YAGNI
  • Changes route structure which could affect deep links

Bottom Navigation: Unified or Role-Flexible?

Currently Creator has 7 icons, Business has 5, Brand has 6. How many should the unified nav have?

A

Strict 5 Icons (Your Proposal)

Home  |  Campaigns  |  +  |  Messages  |  Profile

Cleanest. Earnings, Analytics, Applied, Projects all move to sidebar/dashboard only. The "+" button adapts per role (Create Campaign vs Quick Apply).

Pros

  • Maximum simplicity
  • Identical nav across all roles
  • Messages gets prominent placement (currently missing for creators)

Cons

  • Creators lose quick access to Earnings
  • Brands lose quick access to Analytics
  • 7→5 is a big change for existing creator users
B

Unified 5 + 1 Role Slot

Home  |  [Role]  |  +  |  Messages  |  Profile

Same 5-icon layout, but slot 2 adapts: Campaigns (Business) · Earnings (Creator) · Analytics (Brand). Same visual pattern, role-specific utility.

Pros

  • Still looks unified — same icon count, same layout
  • Each role keeps their most-used shortcut
  • Minimal disruption to existing habits

Cons

  • Not perfectly identical across roles
  • Slightly more nav config complexity
C

Unified 6 Icons

Home  |  Campaigns  |  +  |  Messages  |  [Role]  |  Profile

6 icons for everyone. Slots 1-4 shared, slot 5 is role-specific (Earnings / Analytics / Creators). Slightly wider but preserves all key shortcuts.

Pros

  • No features lose quick access
  • Campaigns browse available to all roles
  • Moderate simplification from current 7/5/6 spread

Cons

  • 6 icons is tighter on small screens
  • Not as clean as 5

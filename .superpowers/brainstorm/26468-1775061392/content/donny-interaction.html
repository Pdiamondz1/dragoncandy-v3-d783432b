Donny AI Bar — Interaction Model

How should the Donny bar behave when tapped/focused on the dashboard?

A) Chat Sheet

Dashboard
Ask Donny anything...
user taps bar...
Chat Sheet slides up
Hi! I'm Donny. How can I help?
Full conversation UI...

Tap bar = full chat sheet slides up. Current behavior, proven UX. But pulls you away from the dashboard.

B) Command Palette

Dashboard
Ask Donny anything... |
Generate Campaign Find Creators Check Analytics
Inline results appear here — never leaves dashboard

Focus expands inline with chips + results. Stays on dashboard. But complex queries feel cramped.

C) Hybrid Recommended

Dashboard
Ask Donny anything... |
Generate Campaign Find Creators Check Analytics
tap chip = navigate instantly | type query = chat sheet opens
Typing "Help me plan a brunch campaign..."
Chat sheet slides up with query pre-filled

Quick chips stay inline for fast actions. Typing opens full chat sheet for real conversations. Best of both worlds.

Why Hybrid wins

  • 80% of actions are quick taps — chips handle these without leaving dashboard
  • 20% are real conversations — chat sheet gives Donny room to shine
  • Donny gets a MORE prominent home (top of dashboard) after leaving bottom nav
  • Feels like a command center, not a chatbot

Trade-offs

  • Slightly more complex to implement (two interaction modes)
  • Need clear visual transition between inline chips and chat sheet

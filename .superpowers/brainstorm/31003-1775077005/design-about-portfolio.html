Design Decisions

  • About card: White card with bio, skills tags (teal pills from creator_profiles.skills), and rate range (base_rate_per_hour or min_project_budget)
  • Skills: Rendered from the existing skills enum array — no new data needed
  • Rate display: Shows base_rate_per_hour as "$XX per project" — only if set, hidden otherwise
  • Portfolio heading: Added "Portfolio" label above grid for clarity
  • Type badges: Detect image vs video from file extension — "Photo" for images, "Reel" for videos
  • Play overlay: Videos get a centered play button indicator
  • Empty state: Friendly message instead of hiding the section entirely
  • Grid: Shows ALL portfolio items (not skipping first one for hero anymore)

8. Available Campaigns (Swipe Card Stack)

Layout: Header with logo (left) + "Available Campaigns" title + location pin + creator avatar (right) + hamburger. Main area: Tinder-style card stack with peek cards visible behind. Front card: full-bleed hero image (top ~65%), then "Available Campaigns" overlay text, description, company avatar + name row, full-width pink "Apply Now" pill CTA.

Swipe behavior: Swipe right = interested/apply, swipe left = skip/next. Cards animate off-screen with rotation. Next card scales up from behind. Touch/drag gesture support with spring physics.

Tech: Use a lightweight swipe library (e.g., react-tinder-card or custom gesture handler with framer-motion).

Design — Phase 2: Screenshot-Matched Pages (Mobile-First)

All mockups shown at mobile viewport proportions (375px wide). Every element sized for touch targets (min 44px), thumb-friendly zones, and full-screen mobile layouts.

📱 Mobile Design Constraints (All Pages)

  • Viewport: 375–430px width, full device height (100dvh)
  • Touch targets: Minimum 44×44px for all tappable elements
  • Buttons: Full-width (w-full) pill CTAs, min height 48px
  • Padding: px-4 (16px) page gutters, p-4 card padding
  • Font sizes: Body 16px min (prevents iOS zoom), headings 20-28px
  • Bottom safe area: pb-24 to clear bottom nav (80px)
  • Scroll: Vertical scroll with momentum, no horizontal overflow
  • Spacing: gap-3 / gap-4 between elements for thumb comfort

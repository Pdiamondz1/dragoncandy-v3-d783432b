CTA Opens existing CreatorProfileModal

Fallback Behavior

  • No portfolio images: Show avatar. No avatar? Show teal gradient with creator initials.
  • No rating: Hide the star entirely (don't show "★ 0" or "No reviews").
  • No location: Hide the location row — card still looks balanced.
  • No skills: Hide the tag row.
  • No rate: Show only review count, or hide metrics row if both missing.

Interaction

  • Tap card anywhere (except heart) → opens CreatorProfileModal (existing)
  • Tap heart → toggles favorite in localStorage, filled pink heart vs outline
  • "View Profile" button → same as card tap (redundant but expected affordance)
  • No "Contact" button on card — moved inside profile modal to reduce clutter

Note on "projects completed" / "avg delivery time": Your original brief included these metrics. The current creator_profiles table doesn't have these fields. Rather than adding backend changes (which you said to protect), I'm using total_reviews and base_rate_per_hour as the two metrics — data that already exists. We can swap in project metrics later when the backend supports it.

Design Decisions

  • White background replaces pink — cleaner, more professional, lets cards pop
  • "Find Creators" — action-oriented title, not a label
  • Content-type pills — horizontally scrollable, teal active state, maps to creator skills
  • Search bar — uses existing searchTerm filter, just promoted to top-level
  • Sort dropdown — new feature: Relevance (default), Rating, Price low→high, Availability
  • "Filters" button — opens existing AdvancedCreatorFilters as a slide-up sheet (keeps location, rate, platform filters accessible without cluttering the main view)
  • Creator count — moved inline with sort/filter controls

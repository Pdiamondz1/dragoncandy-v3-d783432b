A: Vertical Portfolio Card

Large thumbnail up top, creator info below. Instagram/Pinterest-inspired. Best for showcasing visual work — the thumbnail sells the creator.

Pros

  • Visual-first — great for a content marketplace
  • Natural grid layout (1/2/3 cols)
  • Thumbnail does the selling

Cons

  • Takes more vertical space per card
  • Less info visible per screen

B: Compact Data Rows

Closer to current layout. Small avatar, dense info, scan-friendly. Like a search results list — optimized for comparing many creators quickly.

Pros

  • More creators visible per screen
  • Easy to scan and compare
  • Works great with map split-view

Cons

  • Less visual impact — doesn't showcase work
  • Feels more like a spreadsheet than a marketplace

C: Hybrid (Recommended)

Portfolio thumbnail on the left, data on the right. Best of both worlds — visual showcase + scannable metrics. Similar to Airbnb listing cards.

Pros

  • Shows work AND data at a glance
  • Good density — 2-3 cards visible on mobile
  • Closest to current card shape (less churn)
  • Works in both list and grid layouts

Cons

  • Thumbnail is smaller than Approach A
  • Slightly more complex responsive behavior
